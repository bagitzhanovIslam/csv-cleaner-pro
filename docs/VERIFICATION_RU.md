# Фактическая проверка проекта

Дата: 17 ноября 2026. Среда: Linux, Python 3.14.9, локальное окружение `.venv`. В нём установлен pytest 9.1.1 из существующего локального кэша.

## Выполнено успешно

Команда:

```bash
.venv/bin/python -m pytest tests/test_repository.py -q
```

Результат: **3 passed**.

Эти проверки подтверждают:

- синтаксический разбор исходников Python;
- привязку Streamlit к 127.0.0.1, лимит загрузки 10 МиБ и отключённую телеметрию;
- число записей и согласованность счётчиков строк в демонстрационных CSV/JSON, целостность ZIP-структуры XLSX.

Это не проверки исполнения pandas, openpyxl или интерфейса.

## Блокировка зависимостей

Попытка `python -m pip install -r requirements.txt` не удалась: окружение не разрешает DNS-имя `pypi.org` (`NameResolutionError`). Повторная проверка HTTPS через curl также завершилась ошибкой DNS. В доступном локальном кэше отсутствуют pandas, openpyxl и Streamlit. Использовать sudo и менять глобальные настройки системы не предпринималось.

Команда `.venv/bin/python -m pytest -q` действительно запускалась и завершилась с кодом 2: **3 ошибки при сборке тестов**, отсутствуют `streamlit` и `pandas`. Полный набор тестов **не прошёл и не был выполнен**. Ошибки не заменены пропуском тестов.

Команда `.venv/bin/python -m streamlit run app.py --server.headless true` действительно запускалась и завершилась с `No module named streamlit`. Сервер не запустился. Графическая проверка в браузере и скриншоты не выполнены.

## Что подготовлено, но ещё не подтверждено запуском

Тесты написаны для дубликатов, полностью пустых строк, русской кодировки CSV, XLSX, повреждённых и пустых файлов, выключенных опций, выбранных столбцов, экспорта и повторного чтения, лимитов, текстовых формул и поведения Streamlit. Эти сценарии требуют установленного набора зависимостей.

Демонстрационные CSV и отчёт подготовлены с ожидаемыми значениями; XLSX сформированы как минимальные OOXML-файлы стандартной библиотекой Python. Они прошли проверку целостности архива, но ещё не чтение openpyxl и не сравнение с реальным конвейером очистки. Скрипт `scripts/generate_examples.py` предназначен для пересоздания результатов через настоящую логику после установки зависимостей.

## Завершение проверки в среде с доступом к PyPI

```bash
cd /home/kael/csv-cleaner-pro
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -q
python -m scripts.generate_examples
python -m pytest -q
python -m streamlit run app.py
```

Повторный pytest после генерации нужен, поскольку демонстрационные артефакты изменятся. Проверьте сценарий из `SCREENSHOTS_RU.md` в браузере. Если обнаружатся ошибки, исправьте их до публикации; текущий проект не следует описывать как полностью проверенный.

После успешной проверки обновите этот файл реальным количеством тестов и версиями пакетов. При необходимости сохраните `python -m pip freeze > requirements-tested.txt` как отдельный снимок проверенного окружения. Совместимость всех разрешённых версиями зависимостей и каждой версии Python 3.12+ в текущей среде не проверена.
