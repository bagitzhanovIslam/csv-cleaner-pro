### Безопасный предпросмотр Streamlit

Оба предпросмотра используют `src/csv_cleaner/display.py::for_streamlit`.
CSV содержит текстовые значения, а заполнение медианой добавляет числа float;
заполнение текстом числовых XLSX-ячеек также создаёт смешанный столбец object.
Arrow не может представить такие значения одним типом. Для отображения создаётся
копия: каждый столбец проверяется через PyArrow, и только несовместимые столбцы
переводятся в nullable string. None, NaN и pandas.NA остаются пропусками.
Совместимые числа, строки и даты сохраняют типы. Очистка и экспорт используют
исходный результат, а не копию для предпросмотра.

Проверка: `.venv/bin/python -m pytest -q` — 113 passed на Python 3.14.9,
pandas 3.1.1, PyArrow 26.0.1, Streamlit 1.67.0. Регрессии включают прямой вызов
`pa.Table.from_pandas`, все четыре режима пропусков, оба предпросмотра в AppTest
без автоматического исправления типов, сохранение данных и экспорт CSV/XLSX.
Headless Streamlit запускается; `/_stcore/health` возвращает `ok`.
