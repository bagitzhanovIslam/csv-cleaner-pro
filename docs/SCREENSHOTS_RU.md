# Три настоящих скриншота для README

[README](../README_RU.md) · [English README](../README.md)

Изображений в репозитории пока нет. Снимайте реальное приложение с вымышленными данными из `examples/`; не используйте макеты или сгенерированные изображения.

## Подготовка

1. Выполните установку из README. Откройте терминал в корне проекта, где лежит `app.py`.
2. Создайте каталог `docs/screenshots/` для готовых PNG.
3. Запустите приложение из корня проекта без активации окружения:

   Linux/macOS (включая Fish):

   ```bash
   .venv/bin/python -m streamlit run app.py
   ```

   Windows PowerShell:

   ```powershell
   .venv\Scripts\python.exe -m streamlit run app.py
   ```

4. Откройте http://127.0.0.1:8501. Используйте масштаб 100% и окно около 1440×1000. Снимайте только область приложения штатным инструментом снимков экрана: без вкладок, адресной строки, рабочего стола, уведомлений и личных путей. Не загружайте клиентские данные.

## 1. Исходные данные

Загрузите `examples/demo_input.csv`. Оставьте «Параметры чтения» свёрнутыми, все правила выключенными. Прокрутите к «Исходные данные»: должны быть видны таблица, 6 строк, 4 столбца и 9 пустых значений. Сохраните кадр как `docs/screenshots/01-source.png`.

## 2. Настройки очистки

Прокрутите к «Настройки очистки». Оставьте все столбцы выбранными. Включите «Очистить лишние пробелы», «Удалить дубликаты» и «Удалить полностью пустые строки». В поле «Обработка пропусков» оставьте «Оставить пропуски без изменений». Поле заполнения не используется. Снимите весь блок настроек вместе с кнопкой «Запустить обработку» до её нажатия. Сохраните `docs/screenshots/02-settings.png`.

## 3. Результат

Нажмите «Запустить обработку» и прокрутите к «Результат». Проверьте показатели: 6 → 3 строки, 1 дубликат, 2 пустые строки, 9 → 1 пустое значение, 5 изменений пробелов, 0 заполненных ячеек и 0 строк, удалённых из-за пропусков. Выберите формат `xlsx`, чтобы показать таблицу и обе кнопки скачивания без пояснения к CSV. Сохраните `docs/screenshots/03-result.png`.

Если блок не помещается, увеличьте высоту окна; не уменьшайте масштаб до нечитаемого текста. Сохраняйте реальные подписи и показатели. Обрезка границ окна допустима, изменение содержимого приложения — нет.
