# Скриншоты интерфейса

Здесь нет сгенерированных картинок, выдаваемых за работающую программу. Снимайте реальное локальное приложение после установки зависимостей.

```bash
cd /home/kael/csv-cleaner-pro
source .venv/bin/activate
python -m streamlit run app.py
```

Откройте http://127.0.0.1:8501 в браузере. Используйте масштаб 100%, окно примерно 1440×1000, закройте личные вкладки и уведомления. Снимок можно сделать штатным инструментом рабочего стола; специальная программа не требуется.

1. **Загрузка и предпросмотр:** загрузите examples/demo_input.csv, оставьте блок параметров чтения свёрнутым. Сохраните `docs/screenshots/01-preview.png`.
2. **Очистка и отчёт:** выберите все столбцы, включите все три правила, нажмите «Запустить обработку». На снимке должны быть видны 6 → 3 строки, 1 дубликат и 2 пустые строки. Сохраните `02-result.png`.
3. **Экспорт:** выберите XLSX, покажите очищенную таблицу и кнопку скачивания. Сохраните `03-export.png`.

Создайте папку `docs/screenshots/` перед сохранением. Если всё не помещается, сделайте два снимка без уменьшения текста до нечитаемого размера. Скриншоты должны показывать только вымышленные данные из examples.

Скачайте CSV и XLSX, загрузите их обратно и убедитесь, что результат содержит три строки, кириллица читается, код `001` сохранён. Дополнительно попробуйте examples/demo_input.xlsx. Проверьте ошибку на пустом файле и повторную обработку с выключенными переключателями: должно остаться шесть строк.
