## Воспроизведение

[Команды Playwright](../TESTING.md) запускают браузерную проверку и обновляют снимки.
Для обычного запуска приложения Playwright не требуется.

Для ручной съёмки откройте приложение, выберите English и загрузите
`examples/demo_input.csv`. Размер окна: 1440×1100, масштаб: 100%.

1. Снимите загруженную исходную таблицу с выключенными правилами очистки.
2. Включите Trim extra whitespace, Remove duplicates, Remove fully empty rows.
   Оставьте Keep missing values unchanged. Снимите настройки и кнопку Run cleaning.
3. Нажмите Run cleaning и выберите XLSX. Снимите результат с метриками и скачиванием.

Ожидается 6 → 3 строки, 1 дубликат, 2 пустые строки, 9 → 1 пропуск и 5 изменений
пробелов. Имена снимков приведены в таблице выше.
