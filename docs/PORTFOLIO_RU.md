# Материалы для портфолио

## Название работы

CSV Cleaner Pro — очистка CSV и Excel с отчётом и экспортом

## Описание для Freelancehunt

Разработал учебный проект локального приложения для обработки CSV и Excel на Python. Пользователь загружает таблицу, видит первые 20 строк, выбирает столбцы и правила очистки: удаление дубликатов, полностью пустых строк и лишних пробелов, обработку пропусков в выбранных столбцах (сохранение, удаление строк, заданное значение или медиана). Приложение показывает количество строк до и после обработки, число удалённых записей, заполненных ячеек и оставшихся пропусков по столбцам. Результат скачивается в CSV или XLSX, отчёт — в JSON.

Логика обработки отделена от интерфейса Streamlit. Предусмотрены ограничения размера файлов, выбор кодировки и разделителя CSV, сообщения об ошибках и автоматические тесты основных сценариев. Исходный файл не перезаписывается; удаление данных включается только пользователем.

Проект показывает мои навыки автоматизации табличных задач на Python. Это самостоятельный учебный проект для портфолио, а не выполненный коммерческий заказ. Демонстрационные данные вымышленные. Фактический статус запуска тестов указан в README и журнале проверки.

## Короткое описание GitHub

Local Streamlit app to clean CSV and Excel files with explicit rules, previews, opt-in missing-value handling, JSON reports, and CSV/XLSX export.

Suggested topics: `python`, `pandas`, `streamlit`, `csv`, `excel`, `data-cleaning`, `automation`, `pytest`, `portfolio-project`.

## Навыки и технологии

Python 3.12+, pandas, openpyxl, Streamlit, pytest, Git, Linux; обработка CSV/XLSX, кодировки UTF-8/UTF-16/cp1251, валидация данных, дедупликация, отчёты, разделение интерфейса и логики, type hints, тестирование пограничных случаев.

Не указывайте PostgreSQL, FastAPI, SQLAlchemy или коммерческий опыт как часть этого проекта: они здесь не используются.

## Перед размещением

1. Выполните весь pytest в окружении с установленными зависимостями и исправьте возможные ошибки; текущие ограничения проверки описаны в VERIFICATION_RU.md.
2. Пройдите сценарий из SCREENSHOTS_RU.md и сделайте настоящие скриншоты.
3. Прочитайте LEARNING_GUIDE_RU.md, выполните задания и убедитесь, что можете объяснить правила удаления строк.
4. Укажите своё имя в LICENSE при желании. Не добавляйте клиентские файлы, секреты или реальные персональные данные.
5. Создайте репозиторий GitHub и опубликуйте самостоятельно только после проверки. Для Freelancehunt выберите 2–3 скриншота и добавьте ссылку на репозиторий.
6. Адаптируйте каждый отклик под задачу клиента. Не обещайте точный срок, пока не изучены пример файла и правила.
